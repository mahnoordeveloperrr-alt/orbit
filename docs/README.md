# Orbitabs project map

- `src/` — extension popup and application logic
- `public/` — Chrome extension manifest, icons, background worker, and injected markup UI
- `scripts/` — verification and maintenance scripts
- `cloud-api/` — Cloudflare Worker API
- `tab-saver-backend/` — optional Express backend
- `site/` — public website and privacy page
- `ui/` — UI references and verification screenshots
- `store-assets/` — store promotional artwork
- `releases/` — packaged store builds, including archived versions
- `docs/` — audits, test reports, launch instructions, product specs, and privacy policy

Start with the root `README.md` for setup and product overview. Build output (`dist/`) and installed dependencies (`node_modules/`) are generated folders; they are not source code.
